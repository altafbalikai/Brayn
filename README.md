Brayn AI

⚡Live : https://brayn-ai.vercel.app/

Brayn AI is a modern, multi-model AI chat web application designed for fast, secure, and customizable conversations with large language models.
It focuses on clean UX, model flexibility, and production-grade architecture, making it suitable for both personal use and enterprise-level experimentation.

✨ Features :-
  Chat-style AI conversations
  Switch LLM models mid-conversation
  Multi-model support (OpenAI, Meta, NVIDIA, Gemma, local LLMs, etc.)
  Conversation history & persistence
  Streaming responses
  Secure authentication
  Optimized performance with virtualization
  Dark mode, glass-morphism UI

🏗 Tech Stack
  Frontend
    React
    Redux Toolkit
    Tailwind CSS
    React Icons
    Virtualized message list
  Backend
    Node.js
    Express
    JWT Authentication
    Rate limiting & security middleware
    REST APIs
  AI / LLM
    Multiple LLM from OpenRouter LLM provider
    Model-agnostic architecture
    Streaming token handling
